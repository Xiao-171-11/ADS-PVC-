- **主循环**：仅做"判帧 → 图像处理"，无阻塞等待；

## 2. 图像链（约 50 fps）

调用顺序（`SATA_MAIN.c:39-54`）：

```
mt9v03x_finish_flag=0
Camera_Process_Once()   // Camera_REMAIN.c:177  全局大津 → 二值化 → 显示
Zebra_Scan()            // Zebra_REMAIN.c:102   斑马线投票 + 起停状态机
Find_Badpoint(...)      // Badpoint_REMAIN.c     边缘基点（起点）
Find_Bedline(...)       // Bedline_REMAIN.c:206  向上逐行跟踪 + 最小二乘拟合
Find_MIDLine()          // MIDLine_REMAIN.c:79   加权中线 + 互补滤波 + 十字锁定
*_Show_On_TFT180()      // 五组叠加显示
```

### 2.1 二值化：全局 Otsu
`Camera_Otsu_Threshold()`（`Camera_REMAIN.c:60-115`）：整帧 188×120=22560 像素统计 256 bin 直方图，遍历 256 个候选阈值取最大类间方差 `w0*w1*(μ0-μ1)²`；阈值命中 0/255 时回退 128（`Camera_REMAIN.c:185-188`）。
`Camera_Binarize()`（`:126-137`）：先 `memcpy` 整帧再逐像素比较写 `base_image`（0=黑线，255=背景）。

> 特征：**单阈值、全图、逐像素**。光照不均（远端暗角、灯光反光）时必然出现"近处过曝/远处全黑"。

### 2.2 基点（起搜点）
`BADPOINT_ROW = MT9V03X_H-4`（`Badpoint_REMAIN.h:18`），即最贴车头的第 116 行；整行同色时向上最多重试 5 行（`:19`）。

### 2.3 边线基线：逐行搜索 + 最小二乘拟合**一条直线**
`bedline_track()`（`Bedline_REMAIN.c:133-195`）：
- 从基点开始逐行向上，每行在 `±BEDLINE_SEARCH_GAP(6)` 列内先向**赛道外侧**再向**内侧**找"内→外"色变点（`bedline_is_transition()` `:57-64`）；
- 连续丢 `BEDLINE_MAX_LOST(6)` 行则终止；单侧最多 `BEDLINE_MAX_POINTS(60)` 点；
- `bedline_fit()`（`:72-121`）对全部点做**一次最小二乘**，得到 `col = k*row + b`，`row_start/row_end/col_end` 一并输出。

`Find_MIDLine()`（`MIDLine_REMAIN.c:79-290`）逐行取两侧拟合线的列号：两侧都有 → 取中点并累加赛道宽度；只有单侧 → 用上次半宽推算并把该行权重 × `MIDLINE_ONE_SIDE_SCALE(0.5)`（`:173-178`）。
每行权重 `w[row] = 1 + 0.2*row`（`MIDLine_REMAIN.c:65`，`MIDLINE_WEIGHT_MIN/GAIN`），也就是**越靠近车头权重越大**；加权平均得到 `mid_line`。

### 2.4 滤波与偏差
`center = 0.2*last + 0.8*now`（`MIDLine_REMAIN.c:208-209`，`MIDLINE_FILTER_OLD/NEW`），`error = center - W/2`（`:211`）。

### 2.5 十字/路口
`MIDLINE_CROSS_EN=1`（`MIDLine_REMAIN.h:26`）：主判据"实测宽度 > 学习宽度 × 1.25"（`:223`），次判据"有效行 < 12 且宽度 > 1.1 倍"（`:227-231`）；中线已偏出 ±30 像素则否掉（`:232-235`）；连续 2 帧可疑即锁定 40 帧（`:254-258`），锁定期间**强制走直线**（`:273-281`）。

### 2.6 斑马线起停
`zebra_detect()`（`Zebra_REMAIN.c:45-93`）：在 `row 82..118` 每行数黑条长度落在 `[2,22]` 像素的条数，≥5 条且白占比 ≥25% 记该行合格，≥3 行合格即本帧命中。
状态机 `0 等待→1 行驶→2 终点`（`:125-162`），带 2 帧去抖、25 帧消失确认、发车后 150 帧内不许判终点；`Control_Tick()` 只在 state=1 时发车（`Control_REMAIN.c:245-262`）。

## 3. 控制链（5 ms / 200 Hz）

`Control_Tick()`（`Control_REMAIN.c:224-...`）实际执行顺序：

1. **发车许可**：斑马线状态 0/2 或上电前 `CONTROL_START_DELAY_MS(1000)` 内 → 电机停、舵机回中、`return`（`:245-262`）；这段静止时间顺手统计编码器噪声峰值（`:250-260`）。
2. **噪声门限**：`control_noise = peak+1`，封顶 3 脉冲/5 ms（`:264-286`）；运行中低于门限的速度直接归零（`:334-346`）。
3. **超速看门狗**：实测速度 > 180 脉冲/5 ms 连续 100 拍 → 停 0.5 s 并作废前馈标定；连续 2 次失败退回硬编码前馈（`:351-411`）。
4. **前馈自标定**（`CONTROL_FF_LEARN_EN`，当前 `=0`，`:57`）：三相状态机 `0 爬占空比找死区 → 1 量第一点 → 2 抬 BOOST 量第二点 → 3 两点定直线`（`:412-...`），左右轮分别标定；实测结果已固化为 `CONTROL_FF_GAIN_L/R_DEFAULT = 7.0/8.0`、`OFFSET = 529/484`（`Control_REMAIN.h:52-55`）。
5. **速度闭环**：`duty = gain*speed + offset`（前馈）+ `pid_calc()` 位置式 PID（`:102-121`）修正；`integral_max = out_max/ki`（`:92`）——积分按输出量程反推限幅。
6. **差速**：`ratio = CONTROL_DIFF_K(0.004) * error`，封顶 0.5，`v_内 = base*(1-ratio)`、`v_外 = base*(1+ratio)`（`Control_REMAIN.h:88-91`）。
7. **弯道减速**：`slow = clamp(1 - 0.008*|error|, 0.45, 1)`（`Control_REMAIN.h:95-97`）。
8. **输出限幅**：速度环 `±500`（`CONTROL_PID_OUT_MAX`），总占空比上限 `MOTOR_DUTY_MAX=8000`；`CONTROL_SPEED_MAX=112.5` 为差速后上限、`CONTROL_SPEED_MIN=22.5` 为内侧轮下限。
9. **编码器掉线保护**：平均占空比 > 1200 且速度≈0 连续 200 拍 → 停车 0.5 s 后重试，最多 5 次（`Control_REMAIN.h:74-81`）。

### 3.1 速度环 PID 形式
`pid_struct{kp,ki,kd,integral,integral_max,last_error,out_max}`（`Control_REMAIN.c:24-33`），
`out = kp*e + ki*Σe + kd*(e-last_e)`，积分**clamping 式**限幅，输出对称限幅（`:102-121`）。
> 注意：**微分用的是误差差分，且未做低通**；`ki=0.5`、`integral_max = 500/0.5 = 1000`。

### 3.2 舵机环
`Servo_Set_Turn()`（`Servo_REMAIN.c:80-198`）：
- 偏差一阶低通 `0.65*now + 0.35*last`（`:91`，`SERVO_ERR_FILTER`）；
- **死区 3 像素**（`:96`）；**双段 Kp**：`|e|≤8` 用 1.2，超过后用 `1.2*8 + 4.0*(|e|-8)` 线性外推（`:100-108`），即"近处软、远处硬"的折线增益；
- 微分阻尼 `SERVO_KD=2.0`（`:110`），同样未滤波；
- **出弯保持（exit hold）**：`|e|≥30` 连续 10 拍武装，记录峰值输出；脱离 `|e|≤15` 后把峰值输出锁 `40` 拍（0.2 s）并线性衰减（`:113-194`）——用来补偿舵机机械延迟与"车头还没转过来"的滞后；
- 输出端**非对称限幅**：左 `+70`、右 `-69`（`Servo_REMAIN.h:28-30`），最终 `duty = 464 + SERVO_TRIM - out`（`Servo_REMAIN.c:197`，符号取反是因为占空比增大向左）。

## 5. 结构性缺陷清单（按严重度排序）

| # | 问题 | 位置 | 后果 |
|---|---|---|---|
| 1 | **整条边线只用一条直线拟合**（一次最小二乘） | `Bedline_REMAIN.c:72-121` + `MIDLine_REMAIN.c:146-160` | 弯道处拟合线系统性偏离真实边线，弯越急偏差越大；进弯"打角不足"、出弯"回正过冲" |
| 2 | **无元素识别**：只有十字锁定 + 斑马线 | `MIDLine_REMAIN.c:219-271`、`Zebra_REMAIN.c` | 环岛、坡道、断路、入库、避障一律按"普通弯道"处理，必挂 |
| 3 | **全局单阈值 Otsu** | `Camera_REMAIN.c:60-137` | 光照不均/反光/远处暗 → 二值化退化，边线搜索直接丢线 |
| 4 | **偏差取全图中线的加权平均**，不是前瞻点 | `MIDLine_REMAIN.c:205` | 等于"只看车头"，高速时来不及；前瞻距离无法随速度自适应 |
| 5 | **无陀螺仪**：驱动和中断都已就位，只差一行 `imu660rc_init()`。`isr.c:87-95` 已经写好 EXTI0（`ERU_CH0_REQ0_P15_4`）→`imu660rc_callback()`→`imu660rc_get_quarternion()` 的完整通路，但全工程没有任何 `imu660rc_init()`/`exti_init()` 调用，所以这条中断永远不会触发 | `user/isr.c:87-95`、`zf_device_imu660rc.c:392-396`、`推荐IO分配.txt`（SPI0 留给 ICM20602） | 方向环只有"图像 P+D"，无角速度阻尼；出弯摆动只能靠 `SERVO_KD` 硬顶。**这是全工程里最便宜的一个大改进**：接上陀螺就能拿到 17th / USTB 那种"PID 外独立减项"的阻尼 |
| 6 | **无速度斜坡 / 无非对称限幅** | `Control_REMAIN.c:102-121` | 目标速度阶跃（弯道减速、斑马线发车）时占空比直接跳变，抓地差的车会打滑/点头；加减速能力不对称未利用 |
| 7 | 微分项未低通、`kd` 直接乘误差差分 | `Control_REMAIN.c:114`、`Servo_REMAIN.c:110` | 图像抖动/编码器噪声被放大成高频抖动 |
| 8 | 前馈自标定被关掉（`CONTROL_FF_LEARN_EN=0`），改用固定 `gain/offset` | `Control_REMAIN.h:57` | 换电池电压、换电机、温升后前馈失配，闭环要拿积分硬补 |
| 9 | 无"丢线"降级策略的完整闭环（`CONTROL_LOST_STOP_TICKS=0`） | `Control_REMAIN.h:100` | 长时间丢线时舵机保持最后偏差，车会直冲出赛道 |
| 10 | 图像处理无 ROI 裁剪、无跳行采样；`memcpy` 整帧后再逐像素二值化 | `Camera_REMAIN.c:128-137` | CPU 时间被浪费，留给控制/元素识别的余量小 |
| 11 | 全工程参数都是 `#define`，改动需重编译 | 各 `*_REMAIN.h` | 现场调参效率低（库里有 `seekfree_assistant` + `wireless_uart` 未用） |
| 12 | 主循环与中断共享 `midline_info` 无临界区保护 | `MIDLine_REMAIN.c:23` | 单帧撕裂（概率低，但元素识别状态机会放大这个风险） |
